FAQ

Common questions.

Do I need to install Java first?

No. The launcher scans for existing Java installations and downloads a matching runtime for your game version when needed. You can also point it to a Java path manually.

Does it support genuine (Microsoft) login?

Yes. The open-source build embeds no Microsoft credentials: set the TCL_MS_CLIENT_ID environment variable yourself, or join the TCraft Launcher group (QQ group 1131373915) to get the full edition with built-in Microsoft login. CurseForge downloads accept your own API key in Settings; offline login always works.

Will installing a modpack touch my saves?

No. A modpack installs as a separate instance with its own mods, config and saves. The launcher parses name, icon, game version and loader and asks for confirmation first.

Why does Windows say "unknown publisher"?

Code-signing certificates cost money every year; this personal project doesn't have one. Compare the SHA-256 above, or build from source yourself.

Do you collect my data?

No. There is no telemetry. The launcher only reaches the official or community services you actively use — downloads, multiplayer, skins and login.

Can I modify or sell it?

The code is MIT-licensed: keep the copyright notice and you may use and modify it. Bundled third-party components follow their own licenses — see THIRD-PARTY-NOTICES in the repository.
