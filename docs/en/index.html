Why TCL

Launching a game should be
a quiet thing.

A launcher shouldn't be something you have to study. Open it, pick a version, press start — the rest is its job.

01

One file is everything

The launch core and utility libraries ship as compressed snapshots inside the exe. No installer, no runtime dependencies, no stray DLLs — it even runs from a USB stick.

02

Fast by design

Deferred initialization, on-demand resource dictionaries, fonts and network warmed up in the background. ~2 s cold start, near-zero idle CPU.

03

Pretty, but quiet

Win11-style translucent surfaces with wallpaper, background video, music and theme colors — all optional. Turn it all off and keep a clean list.

Features

Everything you need,
nothing you don't.

From vanilla installs to modpack migration, from real login to LAN play — the parts you actually use are all here.

Version & loader installs

One-click vanilla installs with automatic Java matching. Forge, NeoForge, Fabric, OptiFine and LiteLoader install directly — and failures come back as readable reasons, not stack traces.

Modpacks: just drop them in

CurseForge, Modrinth, MCBBS, MultiMC and HMCL packs are all parsed. Drag a zip in and the launcher shows name, icon, game version and loader before installing.

Isolated instances

Every version gets its own mods, saves, config and Java settings. Organize instances by folder.

Three ways to log in

Microsoft device-code login, offline play, and external Authlib servers. Account cards switch and export.

3D skin preview

Real 3D rendering via WPF, auto-detects classic and slim models, drag to rotate.

Multiplayer without a server

Virtual LAN sessions powered by EasyTier. Create a room, share a code, and join a friend's single-player world. Only Minecraft traffic is forwarded.

Downloads, cleanup & logs

CurseForge / Modrinth search with resumable downloads; a categorized cache cleaner that never touches saves or config; crash analysis that speaks plainly.

FAQ

Common questions.

Do I need to install Java first?

No. The launcher scans for existing Java installations and downloads a matching runtime for your game version when needed. You can also point it to a Java path manually.

Does it support genuine (Microsoft) login?

Yes. The open-source build embeds no Microsoft credentials: set the TCL_MS_CLIENT_ID environment variable yourself, or join QQ group 1081955336 to get the full edition with built-in Microsoft login. CurseForge downloads accept your own API key in Settings; offline login always works.

Will installing a modpack touch my saves?

No. A modpack installs as a separate instance with its own mods, config and saves. The launcher parses name, icon, game version and loader and asks for confirmation first.

Why does Windows say "unknown publisher"?

Code-signing certificates cost money every year; this personal project doesn't have one. Compare the SHA-256 above, or build from source yourself.

Do you collect my data?

No. There is no telemetry. The launcher only reaches the official or community services you actively use — downloads, multiplayer, skins and login.

Can I modify or sell it?

The code is MIT-licensed: keep the copyright notice and you may use and modify it. Bundled third-party components follow their own licenses — see THIRD-PARTY-NOTICES in the repository.
