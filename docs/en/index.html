About

A plain-words answer to "what is TCL?"

TCraft Launcher (short form TCL) is a Minecraft launcher for Windows: portable, single-file, and open source under the MIT license. Its whole job is to keep "set up the game, install the mods, get in" as small as possible — pick a version (vanilla, Forge, NeoForge, Fabric), install a modpack (CurseForge, Modrinth and friends), configure OptiFine shaders, and manage multiple instances and saves, all inside one Win11-style translucent interface.

If you're moving over from PCL (Plain Craft Launcher) or HMCL: TCL can import common instance and modpack formats, and keeps offline login, LAN play, skin and model management intact. If you just want a lightweight launcher that "opens and plays, with nothing stuffed in", that is exactly the niche it occupies. For developers: the full source is public, the built-in translation table ships with four languages (Simplified Chinese, English, Traditional Chinese and a literary-classical variant), and re-licensing is up to you.

FAQ

Common questions.

Do I need to install Java first?

No. The launcher scans for existing Java installations and downloads a matching runtime for your game version when needed. You can also point it to a Java path manually under Settings → Java.

Does it support genuine (Microsoft) login?

Yes. The open-source build embeds no Microsoft credentials: set the TCL_MS_CLIENT_ID environment variable yourself, or join the TCraft Launcher group (QQ group 1131373915) to get the full edition with built-in Microsoft login. CurseForge downloads accept your own API key in Settings; offline login always works.

Will installing a modpack touch my saves?

No. A modpack installs as a separate instance with its own mods, config and saves. The launcher parses name, icon, game version and loader and asks for confirmation first.

How is TCL different from PCL and HMCL?

By strength: PCL2 leads on multi-threaded CN download speeds and its 20+ extension ecosystem; HMCL on cross-platform (Win / macOS / Linux) instance management and modpack import/export. TCL bets on "light": one ~3.5 MB portable file, ~2 s cold start, a Win11-style translucent UI, plus two signature extras — real-time 3D skin preview and plain-language crash analysis. If you just want "open and play, nothing stuffed in", TCL is the most restrained of the three.

Why does Windows say "unknown publisher"?

Code-signing certificates cost money every year; this personal project doesn't have one. Compare the SHA-256 on the releases page, or build from source yourself.

Do you collect my data?

No. There is no telemetry. The launcher only reaches the official or community services you actively use — downloads, multiplayer, skins and login.

Can I modify or sell it?

The code is MIT-licensed: keep the copyright notice and you may use and modify it. Bundled third-party components follow their own licenses — see THIRD-PARTY-NOTICES in the repository.
